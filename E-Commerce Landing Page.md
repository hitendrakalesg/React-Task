# React Developer Intern Technical Assignment

# E-Commerce Landing Page

---

## 📖 Overview

The objective of this assignment is to build a modern, responsive **E-Commerce Landing Page** using **React**.

The application should resemble the landing page of a real e-commerce website with an attractive user interface, responsive design, and reusable React components.

---

## ⏱ Time Limit

**75 Minutes**

---

## 🛠 Technology Stack

Use the following technologies:

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Tailwind CSS / Bootstrap / Material UI (Any one)

---

# Functional Requirements

## 1. Navigation Bar

Create a responsive navigation bar containing:

- Brand Logo
- Home
- Products
- Categories
- About
- Contact

On the right side display:

- Search Icon
- Shopping Cart Icon
- User Profile Icon

The navigation bar should remain fixed while scrolling.

---

## 2. Hero Section

Create an attractive hero section containing:

- Large promotional banner
- Heading
- Short description
- "Shop Now" button
- "Explore Products" button
- Hero image

Example:

```
Discover the Latest Collection
Upgrade your lifestyle with premium products at amazing prices.
```

---

## 3. Featured Categories

Display at least **6 category cards**.

Example categories:

- Electronics
- Fashion
- Furniture
- Groceries
- Sports
- Beauty

Each card should contain:

- Category Image
- Category Name

---

## 4. Featured Products

Display at least **8 product cards**.

Each card should display:

- Product Image
- Product Name
- Category
- Price
- Rating
- Add to Cart Button

---

## 5. Promotional Banner

Create a promotional section displaying:

- Discount Offer
- Short Description
- Shop Now Button

Example:

```
Summer Sale
Up to 50% OFF on selected products.
```

---

## 6. Why Choose Us

Create a section displaying at least four features.

Example:

- Fast Delivery
- Secure Payment
- Easy Returns
- 24/7 Customer Support

Each feature should include:

- Icon
- Title
- Description

---

## 7. Testimonials

Display customer testimonials.

Each testimonial should contain:

- Customer Image
- Customer Name
- Rating
- Review

Display at least **3 testimonials**.

---

## 8. Footer

Create a footer containing:

### Company

- About
- Careers
- Contact

### Customer Support

- Help Center
- FAQ
- Privacy Policy

### Social Media

- Facebook
- Instagram
- Twitter
- LinkedIn

Display copyright information.

---
